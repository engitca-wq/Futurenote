# FUTURENOTE

تطبيق ملاحظات ذكي لأندرويد وآيفون وآيباد: كتابة بخط اليد، تسجيل صوتي مع تفريغ، تحويل خط اليد لنص، وتلخيص بالذكاء الاصطناعي، مع دعم كامل للعربية.

## الحالة الحالية

مختبر قراءة خط اليد العربي: شاشة كتابة على ورق مسطّر، وكل سطر يتحول لنص باستخدام محرك Google ML Kit Digital Ink على الجهاز نفسه.

## التشغيل

```bash
flutter pub get
flutter run
```

ملف APK يُبنى تلقائيًا مع كل تحديث من GitHub Actions (تبويب Actions ← Android APK ← futurenote-apk).
